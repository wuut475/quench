# 部署到阿里云函数计算（FC）

> 全程在网页控制台完成，不需要本地装 CLI。约 10 分钟。

## 1. 创建函数

打开 <https://fc.console.aliyun.com> → 左侧「函数」→ **创建函数** → 选 **事件函数**。

| 字段 | 填什么 |
|---|---|
| 函数名称 | `water-reminder` |
| 运行环境 | 内置运行时 → **Python 3.9**（3.10/3.12 也行） |
| 代码上传方式 | **使用示例代码** → Hello, world! 示例 |
| 请求处理程序 | `index.handler`（默认，别改） |
| 执行超时 | 30 秒够用 |

> 这一步**不能直接粘代码**：创建页只给示例代码 / ZIP / 文件夹 / OSS 四种方式。先建成 Hello World，下一步再替换。

## 2. 替换代码

生成单文件版本：

```bash
python3 build_fc.py       # → dist/water_fc.py
```

进函数详情 → **函数代码** → 在线编辑 → 点左边 `index.py` → 全选删掉 → 粘贴 `dist/water_fc.py` 的全部内容 → **部署代码**。

> 文件名必须是 `index.py`，入口才对得上 `index.handler`。

**别把 key 写进代码。** 用环境变量：函数详情 → 配置 → 环境变量 → 新增
- 键：`BARK_KEY`，值：你的 Bark key

## 3. 配置定时触发器

函数详情 → **触发器** → 创建触发器：

| 字段 | 填什么 |
|---|---|
| 触发器类型 | 定时触发器 |
| 名称 | `every5min` |
| 触发方式 | **时间间隔** |
| 时间间隔 | **5**（分钟） |
| 触发消息 | 留空 |

间隔必须等于代码里的 `TICK`（默认 5）。窗口判断是 `[排期点, 排期点+5)`，间隔等于窗口长度时正好每个点命中一次。

## 4. 验证

**A. 直接测代码**：点「测试」，返回 `{"fired": false, ...}` 属正常（此刻不在档位上）。返回里能看到今天的 `slots`，单位是「从 00:00 起的分钟数」。

**B. 测推送通道**：把代码里 `TICK = 5` 临时改成 `TICK = 1440` → 部署 → 测试 → 手机会立刻收到一条。**测完必须改回 5 并重新部署**，否则每 5 分钟推一条。

## 5. 看日志

函数详情 → **日志**。每个时间点应该有一次 `{"fired": true, ...}`。

## 常见问题

**Q：改了 `water_lib.json`，云上不生效？**
A：词库是内嵌进单文件的，改完要重跑 `build_fc.py` 再粘一次。

**Q：想让函数立刻按新的排期跑？**
A：不用管，它每分钟都是现算的，代码一部署就是新的。

**Q：能推给多个人吗？**
A：现在只支持一个 `BARK_KEY`。要多人的话，把 key 用逗号分隔、在 `bark()` 里循环发即可。
